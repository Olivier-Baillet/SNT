# Obligatoire

Ces éléments permettent de vérifier les bases du HTML et la structure du site.

Le titre de la page (balise `<title>`) est correct et s’affiche dans l’onglet du navigateur

La page contient **un titre principal (`<h1>`)** et **plusieurs sous-titres (`<h2>` ou `<h3>`)**

La page contient **plusieurs paragraphes (`<p>`)**

Le site contient **au moins 3 pages HTML reliées entre elles**

La navigation entre les pages fonctionne grâce à des **liens (`<a>`)**

Le site contient **au moins 3 images (`<img>`)**

# Optionnels

Réalisez **plusieurs objectifs parmi les suivants**.

Les tâches sont approximativement classées par difficulté croissante.

Vous avez utilisé **au moins deux balises de mise en forme** parmi :

`<strong>`, `<em>`, `<br>`, `<hr>`, `<blockquote>` 

La page contient **une liste** (`<ul>` ou `<ol>`) 

La page contient **un tableau** (`<table>`) 

Les images possèdent une **description avec l’attribut `alt`** 

Une image possède une **légende** (par exemple avec `<figure>` et `<figcaption>`) 

L’auteur ou l’autrice d’au moins **une image est mentionné** 

Vous expliquez **pourquoi vous avez le droit d’utiliser cette image** (domaine public ou licence libre) 

Le site utilise **une feuille de style CSS externe** (`style.css`) 

Le CSS modifie **plusieurs sélecteurs différents** (ex : `body`, `h1`, `p`, `img`, `.classe`, `#id`)  

Vous avez utilisé **au moins une classe CSS personnalisée** 

Vous avez utilisé **au moins un identifiant (`id`) en CSS** 

Les modifications CSS **améliorent réellement l’esthétique du site** (couleurs, marges, taille du texte, images…) 

Le site contient **un menu ou une barre de navigation** 

Les pages possèdent **une organisation claire et logique** 

Les images sont **bien dimensionnées ou alignées grâce au CSS** 

Vous avez modifié **la couleur ou l’apparence des liens** (`:hover`, couleur…) 

Vous avez ajouté **une couleur ou une image de fond** sur le site 

Vous avez ajouté **des marges ou des espacements (`margin`, `padding`)** pour améliorer la lisibilité

Les pages contiennent **du contenu pertinent et suffisamment détaillé**

Le site fonctionne correctement **sans erreur visible**

Sous-total : **…/14 …/14**
